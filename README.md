# 🎄 Hand-Tracking ASCII Christmas Tree ✨

カメラの手の動き・ジェスチャーに連動してリアルタイムに育っていく、インタラクティブなASCIIアートのクリスマスツリーWebアプリケーションです。

単一の `index.html` のみで完結し、ビルドや `npm install` は不要です。

---

## 🌟 主な特徴 & 演出

- **2画面スプリットレイアウト**:
  - **上部（約40%）**: ミラー反転カメラ映像 + MediaPipe による手の骨格トラッキング（白い発光ラインとエメラルドグリーンの関節ドット）。
  - **下部（約60%）**: 深宇宙の星空と、物理スプリングエンジンで吸着・成長する高精細ASCIIクリスマスツリー。
- **左右完全対称の本格ASCIIアート**:
  - 密度の高い美しいもみの木シルエット（`8`, `#`, `/^^^\`）。
  - 水平に大きく伸びる大十字光芒を持つシャンパンゴールドのトップスター。
  - 足元のダークウッドの幹と、金色の雪面・光の波紋。
- **高精度ジェスチャー認識**:
  - 手のひらサイズによる距離の正規化と、連続フレーム一致（デバウンス処理）により、誤認識・通過ポーズでの誤爆を完全防止。

## 🖐️ ジェスチャー操作一覧

| ジェスチャー | アクション | 演出 |
| :--- | :--- | :--- |
| **✋✋ 両手パー** | **キープでツリー育成** | 約2.8秒間保持することで、幹・地面から緑の葉まで下から上へ徐々に成長！ |
| **✌️ ピース** | **カラフル点滅＠** | まばらに配置された `@` オーナメントが様々なジュエルカラーでチカチカ点滅！ |
| **🫶 ハート** | **星点灯** | 頂上のシャンパンゴールドの大十字星が点灯！ |
| **✊ ぐー** | **リセット** | 文字が弾けて四方に散らばり、初期状態へリセット！ |

> 💡 キーボードショートカット（`Space長押し`: 育成、`P`: オーナメント、`H`: 星点灯、`R`: リセット）や画面タップ長押しでも操作可能です。

## 🚀 クイックスタート

ローカルWebサーバーを起動してブラウザで開きます。

```bash
# Python 3 を使って起動する場合
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開き、**「カメラを起動してスタート 🎄」** をクリックしてください。
